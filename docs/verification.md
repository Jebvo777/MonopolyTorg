# Проверка установочной сборки

Дата: 14 октября 2026 года.

В каталог перенесены 967 товаров и 29 разделов. Для 894 товаров использованы изображения из старой копии; для 73 позиций без доступной фотографии предусмотрена нейтральная заглушка. Сохранены 29 PDF-документов и 18 технических статей. Созданы девять изображений, включая обновленный знак логотипа. Состав импорта находится в `manifest.json`, полный реестр товаров — в `products.csv`.

В заключительном этапе выполнены:

- проверка синтаксиса 44 PHP-файлов;
- импорт единого SQL в MariaDB 10.11 и MySQL 8.0;
- обход 1027 адресов и 698 ресурсов без HTTP-ошибок;
- 59 функциональных проверок: корзина, заявки, вложения, защита форм, вход администратора, редактирование, семь CSV-выгрузок, очередь уведомлений и статистика;
- проверка добавления товара в заявку через настоящий браузер;
- 80 измерений ширины публичных страниц и административных экранов при ширине окна 1440 и 390 пикселей: горизонтального переполнения нет, ошибок JavaScript нет;
- просмотр сохраненных скриншотов главной, содержательных страниц, карточек товаров, заполненной заявки и административных форм.

При проверке исправлены отображение импортированных описаний, отправка корзины через JavaScript, обработка кириллицы в административных многострочных полях, совместимость SQL с MySQL 8, перенос длинных наименований и отступы форм и подвала.

Успешный заключительный браузерный запуск: https://github.com/Jebvo777/MonopolyTorg/actions/runs/38528054964

Повторный полный обход всех товаров после заключительных исправлений не выполнялся. Проверка отправки почты проводилась на локальном SMTP-приемнике; реальные письма получателю не отправлялись. Почтовый транспорт на хостинге настраивается по `INSTALL.md`.

Установочный архив содержит готовые распакованные ресурсы и отдельную локальную конфигурацию. Доступы входят только в приватную установочную сборку и не публикуются в репозитории. Контрольные суммы архива и SQL находятся в `release.json` репозитория.
