# Торговая компания «Монополия»

Полноценный сайт на PHP и MySQL на основе предоставленного редизайна и офлайн-копии каталога.

- 967 карточек товаров, 29 разделов, изображения и схемы из исходного сайта.
- 32 заполненные информационные и служебные страницы, поиск, корзина-заявка.
- Администрирование продукции, контента, документов, контактов и настроек.
- Учет заявок, почтовые уведомления, собственная статистика и выгрузки CSV.

Каталог, манифест и карта переноса находятся в `data/` и `docs/`. Двоичные материалы сохраняются в `asset-packs/*.zip`; восстановить их после клонирования можно командой `python3 tools/unpack_assets.py`. Выдаваемый установочный архив уже содержит все изображения и документы в рабочих каталогах.

Веб-корень сервера должен указывать на `public/`. Параметры подключения задаются переменными окружения или в `app/config.local.php`; файл с секретами исключен из Git. Полная инструкция установки будет включена в финальную сборку.

Этапы работы: разбор источников, публичная часть, админка и заявки, сборка, заключительная проверка. Результаты каждого этапа сохраняются отдельным коммитом.
